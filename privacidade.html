Política de Privacidade — DaeRoteiros

Última atualização: setembro de 2026.

O DaeRoteiros é um aplicativo de computador de uso pessoal. Esta política explica como ele trata os dados acessados por meio da sua conta Google.

Dados que o aplicativo acessa

Quando você conecta sua conta do YouTube, o aplicativo solicita permissão de somente leitura para: (1) ver a lista de vídeos do seu canal (títulos, miniaturas e datas de publicação) e (2) ver as análises do seu canal do YouTube. Nenhuma outra informação da sua conta Google é acessada.

Como os dados são usados

Esses dados são usados apenas dentro do aplicativo, no seu computador, para que você vincule vídeos a projetos e consulte informações do seu próprio canal. O aplicativo não publica, edita nem apaga conteúdo no YouTube.

Armazenamento e compartilhamento

Os dados ficam armazenados somente no seu computador. O token de acesso é guardado de forma criptografada pelo sistema operacional. O aplicativo não envia seus dados a servidores do desenvolvedor, não vende e não compartilha dados com terceiros.

Como revogar o acesso

Você pode desconectar a conta a qualquer momento em Configurações do aplicativo, ou revogar a permissão em myaccount.google.com/permissions. Ao desconectar, o token armazenado é apagado do computador.

Uso de dados de usuário do Google

O uso e a transferência de informações recebidas das APIs do Google seguem a Política de Dados de Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado.
